============================================================
스트리밍 알고리즘 파라미터 비교 실험 결과 보고서
============================================================

본 문서는 Wikipedia Clickstream 데이터셋(clickstream-zhwiki-2026-05.tsv)의 
상위 200,000개 레코드를 활용하여 수행한 Bloom Filter 및 Count-Min Sketch의 
파라미터 변경 대조 실험 결과를 기록한 파일입니다.

------------------------------------------------------------
1. 데이터셋 및 기준 점수 (Ground Truth)
------------------------------------------------------------
* 총 처리 레코드 수: 200,000 개
* Ground Truth (set) 메모리: 4096.21 KB
* Ground Truth (dict) 메모리: 3754.77 KB

------------------------------------------------------------
2. Bloom Filter 비교 실험 세트
------------------------------------------------------------
* 고정 파라미터: 해시 함수 개수 (k) = 5개
* 변화 파라미터: 비트 배열 크기 (bf_size)

[종합 대조 데이터]
- Case A (50만)
  * 자료구조 메모리 : 61.09 KB
  * 정답셋 대비 절약률 : 98.51%
  * 오탐률 (FPR) : 12.4500%
  * 초당 처리량 : 99007.23 items/sec
  * 전체 연산 시간 : 2.0201 초

- Case B (150만)
  * 자료구조 메모리 : 183.16 KB
  * 정답셋 대비 절약률 : 95.53%
  * 오탐률 (FPR) : 0.2800%
  * 초당 처리량 : 97920.87 items/sec
  * 전체 연산 시간 : 2.0425 초

- Case C (300만)
  * 자료구조 메모리 : 366.27 KB
  * 정답셋 대비 절약률 : 91.06%
  * 오탐률 (FPR) : 0.0100%
  * 초당 처리량 : 98751.95 items/sec
  * 전체 연산 시간 : 2.0253 초

[실험 분석]
* 공간-정확도 트레이드오프: 비트 배열 크기를 50만에서 300만으로 6배 확장했을 때, 
  오탐률(False Positive Rate)이 12.45%에서 0.01%로 극적으로 감소하며 정답에 수렴함.
* 연산 성능 안정성: 메모리 공간이 6배 늘어났음에도 불구하고 원소당 수행하는 
  해시 연산 수가 고정되어 있어 초당 처리량은 97,000 ~ 99,000 items/sec의 고성능을 일정하게 유지함.

------------------------------------------------------------
3. Count-Min Sketch 비교 실험 세트
------------------------------------------------------------
* 고정 파라미터: 해시 깊이 (d) = 5개
* 변화 파라미터: 테이블 가로폭 크기 (cms_width)

[종합 대조 데이터]
- Case A (5,000)
  * 자료구조 메모리 : 195.70 KB
  * 정답셋 대비 절약률 : 94.79%
  * 평균 절대 오차 (MAE) : 21509.3673
  * 초당 처리량 : 98563.64 items/sec
  * 전체 연산 시간 : 2.0291 초

- Case B (2만)
  * 자료구조 메모리 : 781.64 KB
  * 정답셋 대비 절약률 : 79.18%
  * 평균 절대 오차 (MAE) : 2809.8609
  * 초당 처리량 : 97160.55 items/sec
  * 전체 연산 시간 : 2.0584 초

- Case C (5만)
  * 자료구조 메모리 : 1953.52 KB
  * 정답셋 대비 절약률 : 47.97%
  * 평균 절대 오차 (MAE) : 451.2376
  * 초당 처리량 : 94726.11 items/sec
  * 전체 연산 시간 : 2.1114 초

[실험 분석]
* 오차 제어 능력: 테이블 가로폭을 5,000에서 50,000으로 10배 넓혔을 때, 
  서로 다른 페이지가 같은 버킷에 매핑되어 카운트가 중첩되던 해시 충돌 현상이 억제됨. 
  결과적으로 평균 과다추정 오차(MAE)가 21,509에서 451로 획기적으로 개선됨.
* 메모리 소모 및 처리량 하락: 공간 파라미터 확장에 비례하여 메모리 점유율이 
  최대 1.95 MB까지 선형 증가함. 또한 대형 배열 관리로 인한 오버헤드로 인해 
  초당 데이터 처리량이 98,563개에서 94,726개로 미세하게 감소하는 경향성이 관찰됨.

------------------------------------------------------------
1. 두 알고리즘 모두 데이터의 물리적 전체 크기에 영향을 받지 않고, 
   사용자가 지정한 고정 자원 범위 내에서만 작동하는 스트리밍 구조의 강력한 자원 효율성을 증명함.
2. 허용 가능한 오차 한계(SLA)와 가용한 하드웨어 메모리 제약 조건을 상호 고려하여 
   최적의 하이퍼파라미터 경계점을 도출하는 튜닝 프로세스가 대용량 데이터 환경에서 필수적임을 실험 데이터로 입증함.
